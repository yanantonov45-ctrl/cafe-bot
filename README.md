# 🍔 Cafe Bot — Telegram-бот для заказа еды

Бот приёма заказов для кафе, пиццерии, суши-бара или dark kitchen: меню с категориями, корзина, оформление с доставкой или самовывозом и смена статусов заказа администратором.

## Возможности

**Для клиента**
- меню по категориям, карточка блюда с описанием;
- корзина с ➖/➕ прямо в карточке и в корзине, хранится в БД (не пропадает после перезапуска);
- подсказка «до бесплатной доставки осталось N ₽»;
- оформление: доставка (адрес) или самовывоз → телефон → комментарий → подтверждение;
- уведомления о смене статуса заказа;
- «Мои заказы» — история со статусами.

**Для администратора**
- уведомление о новом заказе с составом, суммой и ссылкой на клиента;
- смена статуса кнопками: Принят → Готовится → В пути → Выполнен / Отменён;
- `/admin` — все активные заказы.

**Бизнес-правила** (настраиваются в `config.py`)
- минимальная сумма заказа;
- платная доставка с порогом бесплатной;
- цены фиксируются в заказе на момент оформления.

## Стек
Python 3.10+, aiogram 3, aiosqlite (SQLite), FSM, uv.

## Запуск
Нужен [uv](https://docs.astral.sh/uv/):
```bash
uv sync                # создаст .venv и поставит зависимости из uv.lock
cp .env.example .env   # вставьте токен и свой Telegram ID
uv run main.py
```
Без uv: `pip install -r requirements.txt`, затем `python main.py`.

## Структура
```
main.py          — запуск
config.py        — меню, цены, правила доставки, статусы
database.py      — корзина и заказы в SQLite
cart.py          — расчёт сумм и тексты заказа
keyboards.py     — клавиатуры
handlers/user.py — меню, корзина, оформление
handlers/admin.py— управление заказами
```
